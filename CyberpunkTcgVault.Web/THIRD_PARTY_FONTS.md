# Third-party fonts

Choom Vault uses the following open-source typefaces and self-hosts them through the Fontsource npm packages during the Angular build. No Google Fonts stylesheet or font file is requested by the browser at runtime.

## Barlow Condensed

- Package: `@fontsource/barlow-condensed`
- Version: `5.3.0`
- Used weights: 500, 600, 700, 800, 900
- License: SIL Open Font License 1.1 (`OFL-1.1`)
- Fontsource package: https://www.npmjs.com/package/@fontsource/barlow-condensed

## Inter

- Package: `@fontsource/inter`
- Version: `5.3.0`
- Used weights: 400, 500, 600, 700
- License: SIL Open Font License 1.1 (`OFL-1.1`)
- Fontsource package: https://www.npmjs.com/package/@fontsource/inter

The installed npm packages retain their upstream licence files and font notices. This file records the font dependencies used by the Choom Vault frontend.
