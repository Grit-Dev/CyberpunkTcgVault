Backend-enforced security

The browser displays it. The API protects it.

The Angular application will never be trusted to decide which private records a user can access. The API reads the user ID and role from the signed JWT and applies ownership checks on every protected database operation.

  • ✓ Password hashing
  • ✓ JWT validation
  • ✓ User ownership filtering
  • ✓ Role-based Admin access
